REIM Runtime content.

This template contains no Minecraft files and no version-specific DLL.
Copy instance.json.template to an instance.json outside the package and pass
-reim-instance="<absolute path>" on the command line. NativeVersion supplies
mc_26.3.dll plus native_version.json/ue_adapter.json; generated/ comes from the
user's own Minecraft 26.3 data.
